# Шымқала бәріне — жоба сайты

Бұл папканың ішіндегі файлдар GitHub репозиторийінің түбіріне жүктеуге дайын.

## GitHub Pages арқылы жариялау

1. GitHub-та жаңа репозиторий ашыңыз.
2. Осы папканың **ішіндегі барлық файлдар мен папкаларды** репозиторийдің түбіріне жүктеңіз. `index.html` түбірде тұруы тиіс.
3. Репозиторийде **Settings → Pages → Build and deployment** бөліміне кіріңіз.
4. **Deploy from a branch**, `main`, `/(root)` параметрлерін таңдаңыз да сақтаңыз.
5. GitHub көрсеткен сайт сілтемесін ашыңыз.

`index.html` файлын компьютерде де тікелей ашуға болады. Сайттағы мәтін, суреттер, презентация және стенд файлдары офлайн қолжетімді; сыртқы дереккөз сілтемелеріне интернет қажет.

## Қаріп

Сайт Noto Sans қарпін жергілікті `assets/fonts/` папкасынан жүктейді. Оның ішінде қазақ әріптері бар. Қаріп SIL Open Font License шартымен таратылған; лицензия мәтіні `assets/fonts/OFL.txt` файлында, бастапқы жоба: https://github.com/google/fonts/tree/main/ofl/notosans.
