# Шымқала бәріне

«Ақылды өлке: болашаққа арналған шешім» ғылыми жобасының жұмыс істейтін веб-нұсқасы.

## Қазір не жұмыс істейді?

- Үш тарихи кезеңі бар интерактивті цифрлық гид.
- Әр кезеңге арналған қысқа және толық түсінік, бастапқы дереккөзге сілтеме.
- Мәтін өлшемін және контрастты өзгерту.
- Жеке мәлімет сұрамайтын сынақ сауалнамасы: жауаптар тек осы браузерде сақталады, CSV түрінде жүктеледі.
- `assets/qr-shymqala.png` файлы — тұрақты Vercel мекенжайына апаратын басып шығаруға болатын QR код.

Бұл — цифрлық шешімнің нақты жұмыс істейтін нұсқасы. Музей аумағында орнату, маманмен келісу және келушілермен ресми сынақ әлі алдағы қадамдар ретінде көрсетілген.

## Vercel

Сайт статикалық: `index.html`, CSS, JavaScript және жергілікті ресурстар. Vercel-де GitHub репозиторийін импорттағанда **Root Directory: `./`**, **Application Preset: Other** параметрлерін таңдаңыз. Build Command бос қалсын. GitHub интеграциясы қосылса, `main` тармағына push жасағаннан кейін жаңа нұсқа автоматты жарияланады.

Терминал арқылы жариялау үшін осы папкада `npx vercel --prod` командасын іске қосуға болады.

## GitHub Pages

`index.html` репозиторий түбірінде тұруы тиіс. GitHub Pages баптауларынан **Deploy from a branch → main → /(root)** таңдаңыз.

## Қаріп пен лицензия

Noto Sans қарпі `assets/fonts/` ішінде сақталған және қазақ әріптерін қамтиды. Лицензия: `assets/fonts/OFL.txt`. Бастапқы жоба: https://github.com/google/fonts/tree/main/ofl/notosans.

Авторлар: Әбдіжапбар Мансұр, Ерментай Ертұр.
